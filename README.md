# BlackMatter PORTAL

Descargas oficiales de BlackMatter PORTAL para macOS.

Descarga el `.dmg` más reciente desde [Releases](../../releases/latest), ábrelo y arrastra la app a Aplicaciones.
La app está firmada con Developer ID y notarizada por Apple. Requiere macOS 10.15 o superior.

Este repositorio solo contiene los instaladores; el código fuente es privado.
